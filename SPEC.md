Project name: Ship Speak. 

Tagline: The voice-first last-mile engine for developers and hackathon builders. 

Problem statement: Developers spend hours writing code but shipping it creates massive cognitive drag. Writing pull request descriptions, breaking change logs, README architecture diagrams, demo video scripts, and social updates. Dreams, momentum when forced into ChatGPT the output is hallucinated and generic because it lacks the developer's raw rational. 

Core-solution: Shipspeak converts an unstructured messy voice brain dump, along with an optional git diff into four structured, developer-grade deliverables in real time. 

Target architecture:

\#1. Next.js 14, App Router, TypeScript, and Tailwind CSS 

\#2. A sleek high-contrast dark developer aesthetic using lucid icons

\#3. left panel input 

Quick load preset bar with three buttons for judges, author factor, AI agent pipeline, and hackathon project. 

Primary text area for voice brain dump with a persistent indicator. Press your Wispr Flow hotkey and ramble here. 

Secondary collapsible text area for `git diff` or file tree context 

A prominent Generate Deliverables action button

\#4. Right Panel Bento Grid 

Card 1: GitHub PR and commit title, summary, bullet points, and breaking changes. 

Card 2: Visual architecture flowchart dynamically rendered using mermaid.js with a code toggle. 

Card 3: 2-minute hackathon demo video script with exact timestamp buckets 

Card 4: Technical, build-in public, post formatted for Twitter and LinkedIn 

\#5. Interactive polish

One-click copy buttons on all four cards with visual feedback 

A voice tweak input box at the bottom of each card, allowing targeted voice edits 

A mock fallback dataset matching the three judge presets so the app remains interactive even without live API credentials
